# Footwork Trainer

A mobile-first badminton footwork trainer inspired by numbered-zone reaction drills. Open the app on a phone or tablet, start a round, and move toward the displayed zone number.

## Features

- Six-zone badminton court display
- Random, no-repeat, corner-only, and front/back chain modes
- Configurable cue pace and round length
- Countdown, progress, rep count, recent cue history
- Optional sound, voice calls, fullscreen mode, and screen wake lock
- Keyboard shortcuts: Space to start/pause, N for next cue, R to reset

## Run locally

Serve the folder with any static or PHP server, then open the local URL:

```bash
php -S 127.0.0.1:8000
```

The app is self-contained in `index.html`; `index.php` includes it for PHP-first hosts.
